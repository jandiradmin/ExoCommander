## English

A fast, native two-panel file manager for macOS in the spirit of Far Manager and Total Commander: keyboard first, SFTP servers as folders, archives as folders, a command line under the panels, user commands on F2, Multi-Rename and Find Files.

- **Download:** [latest release](https://github.com/jandiradmin/ExoCommander/releases/latest) — unzip and move ExoCommander to Applications. The first time, open it with a right click → Open (the app isn't notarized by Apple yet).
- **Website and guide:** [exocommander.top](https://exocommander.top)
- **Requirements:** macOS 13 Ventura or later, Apple silicon or Intel.
- **Bugs and ideas:** [Issues](https://github.com/jandiradmin/ExoCommander/issues)

This repository holds the releases; the source code is not public.

## Українська

Швидкий рідний двопанельний файловий менеджер для macOS у дусі Far Manager і Total Commander: усе з клавіатури, SFTP-сервери й архіви як теки, командний рядок під панелями, власні команди на F2, групове перейменування й пошук файлів.

- **Завантажити:** [остання версія](https://github.com/jandiradmin/ExoCommander/releases/latest) — розпакуйте й перенесіть ExoCommander у «Програми». Першого разу відкрийте правою кнопкою → «Відкрити» (застосунок поки не завірений Apple).
- **Сайт і документація:** [exocommander.top/uk](https://exocommander.top/uk/)
- **Вимоги:** macOS 13 Ventura або новіша, Apple silicon чи Intel.
- **Помилки та ідеї:** [Issues](https://github.com/jandiradmin/ExoCommander/issues)

## Русский

Быстрый родной двухпанельный файловый менеджер для macOS в духе Far Manager и Total Commander: всё с клавиатуры, SFTP-серверы и архивы как папки, командная строка под панелями, свои команды на F2, групповое переименование и поиск файлов.

- **Скачать:** [последняя версия](https://github.com/jandiradmin/ExoCommander/releases/latest) — распакуйте и перенесите ExoCommander в «Программы». В первый раз откройте правой кнопкой → «Открыть» (приложение пока не заверено Apple).
- **Сайт и документация:** [exocommander.top/ru](https://exocommander.top/ru/)
- **Требования:** macOS 13 Ventura или новее, Apple silicon или Intel.
- **Ошибки и идеи:** [Issues](https://github.com/jandiradmin/ExoCommander/issues)
